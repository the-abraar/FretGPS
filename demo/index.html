What is real and what is simulated: the notes are the first 12 s of a real GuitarSet solo (04_Jazz1-130-D), with the true string and fret from a hexaphonic pickup. There is no audio here. The pitches go in exactly, with the strings hidden, so this shows only the placement step of fretmap.py, ported to JavaScript. The hint is set by you, so it is perfect. Every hint result here is an upper bound on what a real "around fret N" or a camera would get.

Audio knows the pitch, not the place

Most notes on a guitar can be played in 2 to 5 places. The circles are where the player actually was. The dots are where the software guessed. A guess is blue when it is on the right string and orange when it is wrong.

Try a wrong hint too. On this solo "around 12" puts 1 note of 28 on the right string, which is worse than no hint at all.
